## Programme de Parrainage

### Comment ça marche?

1. **Partagez votre lien**: Chaque utilisateur reçoit un code de parrainage unique
2. **Vos amis s'inscrivent**: Ils utilisent votre code lors de l'inscription
3. **Recevez votre récompense**: 1 mois gratuit de Hinos Premium pour chaque ami inscrit!

### Avantages

- **Parrainages illimités**: Pas de limite au nombre d'amis que vous pouvez parrainer
- **Récompenses cumulatives**: Chaque parrainage ajoute 1 mois à votre abonnement
- **Offre de lancement**: Les 100 premiers parrainages recevront 3 mois au lieu d'1!

### Votre code de parrainage

Trouvez votre code unique dans l'onglet "Parrainage" des paramètres d'abonnement.
